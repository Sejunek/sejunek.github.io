# Borrowed Gravity

**GPT-6 · 2026.09 · 대화 2회, 수정 2회**
900개의 잉크 조각이 손끝의 중력을 따라 모이고 흩어지는 Canvas 2D 스케치입니다. 대화는 추가 요청과 재개 요청 두 번, 수정은 초기 구현 후 입력 보정과 최신 규약 반영의 두 차례 작업을 뜻합니다.

## 시작 프롬프트

> 규약대로 새 인터랙션 스케치를 하 나 더 만들어서 추가해줘.

## 이어진 요청

> 이거 계속 진행. 다만 그 웹이 조금 바꼈으니까, 웹 디자인은 절때 건들지 말고 작품만 추가

## AI가 스스로 정한 것

- 기존 Grid Field와 Memory Surface가 격자를 다루므로, 이번에는 연결선이 없는 잉크 조각의 흐름을 소재로 골랐습니다.
- 제목은 Borrowed Gravity, 이야기는 "손끝에 머문 작은 중력. 놓아준 뒤에도, 흐름은 기억한다"로 정했습니다.
- 세 갈래 나선 궤도, 비어 있는 중심, 파란색·검정·회색의 짧은 획으로 형태를 만들었습니다. 외부 라이브러리 없이 단일 HTML 안의 Canvas 2D로 그립니다.
- 손끝을 따라 중력의 중심이 움직이고, 길게 누르면 궤도가 조여들며 회전이 빨라집니다. 놓으면 조각에 바깥 방향의 속도를 더합니다. REVERSE는 회전 방향을 바꾸고, PAUSE는 흐름을 멈춰 관찰하는 조작입니다. 캔버스에 초점이 있을 때 Space로 모으고 R로 초기화할 수 있습니다.
- 입자 개수를 720개에서 900개로 늘리고 짧은 획을 길게 조정해 모바일과 카드 크기에서 형태가 더 잘 보이게 했습니다. 색과 굵기별로 아홉 경로에 모아 그립니다.
- 최신 규약에 맞춰 스케치 내부 제목·소개·장식·RESET 버튼을 제거했습니다. 작품을 가운데 배치하고 안내 한 줄과 고유 조작 두 개만 남겼습니다.
- 별도 검토에서 키보드와 포인터를 함께 쓸 때의 입력 소유권, 페이지 복귀 시 남는 누름 상태, 취소 시 포인터 캡처 해제 누락을 찾아 보정했습니다.
- 포스터는 UI를 숨기는 poster 모드로 실제 스케치를 정지 상태에서 실행해 캡처했습니다. 브라우저의 캡처 결과를 64색 PNG로 변환했으며 구성 요소를 합성하거나 다시 그리지 않았습니다.

- 이번 작품의 소재, 제목, 색 배치, 입력 방식, 구현 도구는 따로 지정하지 않았습니다.
- 사용자는 작업을 재개하면서 바뀐 웹 디자인을 절대 수정하지 말고 작품만 추가하라고 지정했습니다. 공용 페이지와 스타일은 수정하지 않았습니다.
