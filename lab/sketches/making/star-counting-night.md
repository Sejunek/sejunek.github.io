**GPT-6 Astra Light · 2026·09 · 대화 3회, 수정 1회**
윤동주의 시에서 출발해 별이 기억의 윤곽으로 모이는 세 장면을 만들었습니다.
모델 표기는 이 대화에서 사용자가 지정한 명칭을 유지했습니다. 대화 횟수는 이 작품의 기획 요청과 구현 요청 기준입니다.

> 내가 윤동주를 좋아하니까 윤동주 선생님의 시 별헤는 밤을 인터랙션으로 만들고 싶어. 별헤는 밤을 보면 윤동주가 별을 보면서 성찰을 하는데, 거기에 나오는 요소들을 별들이 막 흩어져있다가 별들이 모이면서 그 요소들의 형상이 됐으면 좋겠음. 추억, 사랑, 쓸쓸함, 동경, 시, 어머니, 패, 경, 옥, 프랑시스 잠, 라이너 마리아, 릴케 등 요소들이 나타나면 좋겠다. 단, 어떠한 인터랙션(마우스 클릭, 휠, 타자 등)으로 이런 것들을 표현할 지 아직은 모르겠다. 한번 먼저 기획을 해보라/

## AI가 스스로 정한 것

- 기획에서 제안한 첫 시안 범위인 추억·쓸쓸함·어머니 세 장면을 구현했습니다.
- 두 책상과 책, 빈 의자, 고개를 숙인 인물의 옆모습은 AI가 정한 시각적 해석입니다. 실제 윤동주의 기억이나 어머니의 외모를 재현한 것이 아닙니다.
- 외부 라이브러리·폰트·이미지를 요청하지 않는 단일 HTML로 만들었습니다. SVG 경로를 샘플링한 1,400개 입자와 620개 배경별을 Canvas 2D로 그립니다.
- 별 선택 후 약 4.5초 동안 형상으로 모이고, 빈 하늘을 누르면 약 3초 동안 흩어집니다. 형상의 감상 시간은 사용자가 결정합니다.
- 세 장면을 본 뒤에는 사용자가 떠올린 이름을 입력해 별로 나타낼 수 있습니다. 이름은 저장하거나 전송하지 않으며 페이지를 닫으면 사라집니다.
- 남색 하늘은 작품 내부의 색감입니다. 사이트의 전역 디자인과 기존 스케치는 수정하지 않았습니다.
- 일시정지와 동작 줄이기 설정에서는 별빛과 시차 효과를 멈추고, 장면 선택은 정지된 결과로 표시합니다.

- 웹 규약 준수를 명시했습니다.

## 언덕 위의 시인 추가

> 자 이제 좌측 하단에, 윤동주가 언덕 위에 누워서 이 이미지와 같은 느낌으로 누워서 하늘을 바라보고 있는(idle 움직임 포함) 상태였으면 좋겠어.

- 사용자가 첨부한 기대 누운 인물의 자세를 참고해 왼쪽 아래에 낮은 언덕과 시인을 추가했습니다. 기존 밤하늘과 별의 형상은 유지했습니다.
- 참고 이미지의 자세를 새 Canvas 벡터 일러스트로 해석했습니다. 윤동주의 실제 사진을 복제한 초상은 아닙니다.
- 팔로 몸을 지지하고 무릎을 구부린 채 오른쪽 위 하늘을 바라보는 모습으로 구성했습니다. 옷과 풀에는 차가운 별빛 색을 사용했습니다.
- 인물의 호흡과 고개의 미세한 움직임, 풀의 흔들림을 기존 시간 루프에 연결해 PAUSE, 동작 줄이기, 백그라운드 정지와 함께 멈추도록 했습니다.
- 데스크톱에서 선택 별을 오른쪽으로 조정하고 모바일에서는 인물이 선택 영역 위에 위치하게 했습니다. 조정은 이 스케치 내부에만 적용했습니다.

- 헤드리스 Chrome 1280×800에서 약 3초간 실제 렌더 프레임을 측정해 평균 59.9fps를 확인했습니다. 인물 포함 장면의 움직임, 일시정지·동작 줄이기 상태의 동일한 캔버스 이미지, 375×812 및 800×400 배치와 선택 버튼을 검증했습니다. 콘솔 오류와 JavaScript 예외는 0개였습니다.
- 인물이 포함된 새 장면으로 카드와 커버를 갱신했습니다(각각 39,558 / 50,329바이트). 목록·공용 뷰어·제작 기록 렌더링과 모바일 뷰어 실행을 확인했고 오류는 0개였습니다.

## Claude가 이어서 한 것 (2026.09)

> 마음에 안들어서 너가 좀 수정해봐라. 윤동주는 좀 더 작아도 되고, 색이 안들어가고 그냥 실루엣의 뒷모습만 나오면 된다. (…) 별 하나의 추억, 별 하나가 중요한건데 (…) 마우스를 꾹 누르고 있으면 랜덤으로 모양이 만들어지고, 이걸 때면 다른 랜덤으로 요소가 나오면 좋겠다. (…) 윤동주 옆에 나무도 하나 있었으면 (…) 나무와 윤동주 전체적으로 스케일을 많이 줄여서 광활한 하늘이 표현되면 좋다

GPT가 만든 판(23,534자)은 선택 버튼 3개 · 이름 입력 dialog · PAUSE 버튼 · 마을 SVG로 이루어져 있어서, 위 요청과 구조가 맞지 않았습니다.
부분 수정으로는 남는 코드가 더 많아져 **Canvas 2D로 새로 썼습니다**(14,975자). 바꾼 것과 이유는 아래와 같습니다.

1. **인물** — 색을 모두 빼고 `#010206` 단색 뒷모습 실루엣으로 다시 그렸습니다. 누운 자세 대신 서서 하늘을 보는 자세입니다. 100단위 로컬 좌표계에서 다리·팔·목·머리를 따로 그려, 작게 줄여도 사람으로 읽히도록 했습니다. 크기는 `min(h*0.105, w*0.062)`.
2. **나무** — 인물 옆에 실루엣 나무를 추가했습니다. 줄기는 위로 갈수록 더 휘는 2차 곡선, 가지 4개, 잎은 크기와 각도가 제각각인 타원 8개입니다. 바람은 `sin(t*0.55)*0.6 + sin(t*1.31+1.1)*0.22` 두 주기를 겹쳐, 규칙적으로 보이지 않게 했습니다. 동작 줄이기 설정에서는 0.
3. **하늘의 비율** — 지평선을 `h*0.88`까지 내리고 인물·나무를 크게 줄여, 화면의 대부분이 하늘이 되도록 했습니다.
4. **별 하나** — 밝은 별을 6개로 줄이고 헤일로·십자 플레어·흰 코어를 줘서 하나하나가 보이게 했습니다. 나머지 760개는 아주 희미하게 두어, 모일 때만 형태가 됩니다.
5. **선택 UI 삭제** — 추억/사랑/어머니 버튼과 dialog를 모두 없앴습니다. **누르고 있으면** 희미한 별들이 랜덤 도형(장미곡선·리사주·별다각형·나선·초타원·고리)으로 모이고, **떼면** 흩어지면서 밝은 별 하나가 새로 생기고 시구 한 줄이 잠깐 나타납니다. 키보드는 Space·Enter로 같게 동작합니다.
6. **형태가 윤곽선으로만 보이던 문제** — 처음엔 테두리에만 별이 붙어 고리처럼 보였습니다. even-odd 내부 판정(`inside`)을 넣고 테두리 30% · 내부 70%로 rejection sampling 하도록 고쳐, 채워진 실루엣으로 읽히게 했습니다.
7. **정리** — 제목·부제·PAUSE·마을 SVG를 빼고, 하단 한 줄 안내(`PRESS AND HOLD`)만 남겼습니다. LAB 뷰어가 제목을 이미 표시하므로 스케치 안에서 중복되면 안 됩니다.

검증: 1440×760 헤드리스 Chromium에서 **61fps, 콘솔 오류 0개**. idle / hold / 다른 hold / release 네 상태를 스크린샷으로 확인했습니다. 카드·커버 이미지는 새 장면으로 다시 찍었습니다.

*GPT가 틀려서 고친 것이 아니라, 기획이 바뀌어 구조가 맞지 않았기 때문입니다.*

### 고정과 여운 (2026.09, 2차)

> 마우스 따라서 요소가 따라오는 게 아니라 마우스 클릭한 위치에 고정적으로 있다가 천천히 사라지게 해줘. 여운이 느껴지도록. 대신 클릭을 약 2~3초 정도 꾹 누르고 있어야 고정되게 하면 좋을거 같아

- 형상이 맺히는 자리를 **누른 지점**으로 바꿨습니다. 이전에는 화면 가운데 근처에서 무작위로 잡혔습니다.
- **2.4초** 이상 누르고 있어야 고정됩니다(`LOCK`). 그전에 떼면 형상이 맺히지 못하고 흩어지며, 밝은 별도 시구도 남지 않습니다.
- 차오르는 동안 형상 둘레에 아주 옅은 호가 한 바퀴 돌아 남은 시간을 알립니다. 별빛도 30%에서 100%까지 같이 차오릅니다.
- 손을 떼면 흩어지지 않고 **그 자리에 그대로 머문 채 4.2초에 걸쳐 옅어집니다**(`LINGER`). 다 사라진 뒤에야 별들이 보이지 않게 제자리로 돌아가 다시 켜집니다 — 되돌아가는 움직임이 보이면 여운이 끊깁니다.
- 밝기 배수(`mul`)를 별마다 따로 두고, 사라질 때(1.05)와 돌아올 때(2.2) 속도를 다르게 했습니다. 사라지는 쪽이 느립니다.
- 머무는 동안 다시 누르면 남아 있던 형상을 먼저 보내고 새로 시작합니다.

검증: 1200×700에서 61fps, 콘솔 오류 0개. 짧게 누름 / 길게 누름(고정) / 뗀 직후 / 4초 뒤 네 상태를 스크린샷으로 확인했습니다.
