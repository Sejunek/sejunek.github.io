# 별 헤는 밤

**GPT-6 Astra Light · 2026·09 · 대화 3회, 수정 1회**
윤동주의 시에서 출발해 별이 기억의 윤곽으로 모이는 세 장면을 만들었습니다.
모델 표기는 이 대화에서 사용자가 지정한 명칭을 유지했습니다. 대화 횟수는 이 작품의 기획 요청과 구현 요청 기준입니다.

## 시작 프롬프트

> 그 일단 이 프로젝트는 내가 나중에 또 수정할 테니 두고, 또 다른 인터랙션을 만들고 싶어. 기획은 아래와 같아.
> 내가 윤동주를 좋아하니까 윤동주 선생님의 시 별헤는 밤을 인터랙션으로 만들고 싶어. 별헤는 밤을 보면 윤동주가 별을 보면서 성찰을 하는데, 거기에 나오는 요소들을 별들이 막 흩어져있다가 별들이 모이면서 그 요소들의 형상이 됐으면 좋겠음. 추억, 사랑, 쓸쓸함, 동경, 시, 어머니, 패, 경, 옥, 프랑시스 잠, 라이너 마리아, 릴케 등 요소들이 나타나면 좋겠다. 단, 어떠한 인터랙션(마우스 클릭, 휠, 타자 등)으로 이런 것들을 표현할 지 아직은 모르겠다. 한번 먼저 기획을 해보라/

> 좋다 한번 감각적으로 이 인터랙션을 만들어보라. (웹 규약은 지켜야 한다)

## AI가 스스로 정한 것

- 기획에서 제안한 첫 시안 범위인 추억·쓸쓸함·어머니 세 장면을 구현했습니다.
- 두 책상과 책, 빈 의자, 고개를 숙인 인물의 옆모습은 AI가 정한 시각적 해석입니다. 실제 윤동주의 기억이나 어머니의 외모를 재현한 것이 아닙니다.
- 외부 라이브러리·폰트·이미지를 요청하지 않는 단일 HTML로 만들었습니다. SVG 경로를 샘플링한 1,400개 입자와 620개 배경별을 Canvas 2D로 그립니다.
- 별 선택 후 약 4.5초 동안 형상으로 모이고, 빈 하늘을 누르면 약 3초 동안 흩어집니다. 형상의 감상 시간은 사용자가 결정합니다.
- 세 장면을 본 뒤에는 사용자가 떠올린 이름을 입력해 별로 나타낼 수 있습니다. 이름은 저장하거나 전송하지 않으며 페이지를 닫으면 사라집니다.
- 남색 하늘은 작품 내부의 색감입니다. 사이트의 전역 디자인과 기존 스케치는 수정하지 않았습니다.
- 일시정지와 동작 줄이기 설정에서는 별빛과 시차 효과를 멈추고, 장면 선택은 정지된 결과로 표시합니다.

## 내가 판단한 것

- 사용자가 윤동주의 시와 별이 형상으로 모이는 표현을 선택했습니다.
- 상호작용 방식은 AI에게 기획하도록 맡겼고, 제안 후 구현을 요청했습니다.
- 웹 규약 준수를 명시했습니다.

## 검증

- 헤드리스 Chrome, 1280×800, DPR 1에서 완성된 형상을 약 3초간 렌더링하며 측정한 평균은 59.9fps였습니다.
- 세 장면의 모임, 흩어짐, 세 장면 감상 후 이름 입력과 별 글자 표시를 확인했습니다. 콘솔 오류 및 JavaScript 예외는 0개였습니다.
- 375×812 화면을 캡처해 배치를 확인했습니다.
- DPR 3 환경에서 실제 캔버스 DPR 2 제한, 일시정지 중 정지된 장면 선택, 동작 줄이기 정지, 모의 visibilitychange의 렌더 루프 정지를 확인했습니다.
- 목록 카드 클릭, 공용 뷰어 실행, 제작 기록 렌더링과 모바일 폭 통합 화면을 확인했습니다. 해당 경로의 콘솔 오류와 JavaScript 예외는 0개였습니다.
- 실제 어머니 장면을 캡처한 1200×750 카드와 1600×900 커버에서 모든 UI를 숨기고 64색 PNG로 저장했습니다.

## 남은 한계

- 첫 시안에는 세 장면만 포함했습니다. 사랑·동경·시·패·경·옥과 시인들의 이름은 이후 확장 대상입니다.
- 3D 조각이 아닌 2D 별빛 윤곽이며, 시의 전편 낭독과 배경음은 없습니다.
- 설치된 시스템 명조체를 사용하므로 기기마다 글꼴과 이름의 별 모양이 조금 달라집니다.
- 실제 모바일 기기와 Safari는 검증하지 않았습니다.

## 언덕 위의 시인 추가

> 자 이제 좌측 하단에, 윤동주가 언덕 위에 누워서 이 이미지와 같은 느낌으로 누워서 하늘을 바라보고 있는(idle 움직임 포함) 상태였으면 좋겠어.

- 사용자가 첨부한 기대 누운 인물의 자세를 참고해 왼쪽 아래에 낮은 언덕과 시인을 추가했습니다. 기존 밤하늘과 별의 형상은 유지했습니다.
- 참고 이미지의 자세를 새 Canvas 벡터 일러스트로 해석했습니다. 윤동주의 실제 사진을 복제한 초상은 아닙니다.
- 팔로 몸을 지지하고 무릎을 구부린 채 오른쪽 위 하늘을 바라보는 모습으로 구성했습니다. 옷과 풀에는 차가운 별빛 색을 사용했습니다.
- 인물의 호흡과 고개의 미세한 움직임, 풀의 흔들림을 기존 시간 루프에 연결해 PAUSE, 동작 줄이기, 백그라운드 정지와 함께 멈추도록 했습니다.
- 데스크톱에서 선택 별을 오른쪽으로 조정하고 모바일에서는 인물이 선택 영역 위에 위치하게 했습니다. 조정은 이 스케치 내부에만 적용했습니다.

- 헤드리스 Chrome 1280×800에서 약 3초간 실제 렌더 프레임을 측정해 평균 59.9fps를 확인했습니다. 인물 포함 장면의 움직임, 일시정지·동작 줄이기 상태의 동일한 캔버스 이미지, 375×812 및 800×400 배치와 선택 버튼을 검증했습니다. 콘솔 오류와 JavaScript 예외는 0개였습니다.
- 인물이 포함된 새 장면으로 카드와 커버를 갱신했습니다(각각 39,558 / 50,329바이트). 목록·공용 뷰어·제작 기록 렌더링과 모바일 뷰어 실행을 확인했고 오류는 0개였습니다.
