# Moiré Lens

**GPT-6 Astra Light · 2026·09 · 대화 1회, 수정 0회**
두 겹의 선을 이동하고 회전해 모아레 무늬를 만드는 Canvas 2D 스케치.
모델 표기는 사용자가 요청한 명칭을 그대로 사용했습니다. 수정 횟수는 사용자의 후속 수정 요청 기준입니다.

---

## 시작 프롬프트

> `https://github.com/sejunek/sejunek.github.io` 의 `lab/AGENTS.md` 를 먼저 읽고, 규약대로 새 인터랙션 스케치를 하나 만들어서 추가해줘. 현재 GPT-6 Astra Light 모델로 했는 거도 기록.

## AI가 스스로 정한 것

- 기존 격자 및 탄성 표면 스케치와 다른 광학적 간섭 무늬를 주제로 선택했습니다.
- 외부 라이브러리 없이 Canvas 2D로 두 원형 선 레이어를 그렸습니다.
- 드래그와 방향키로 렌즈를 옮기고, 각도 슬라이더 및 RESET 버튼을 제공했습니다.
- 입력 후 렌즈가 목표 위치에 도달하면 렌더 루프를 멈춥니다. 백그라운드에서는 중단하며 동작 줄이기 설정에서는 보간 없이 정지 화면으로 갱신합니다.
- 카드와 커버는 로컬 HTTP 서버에서 실제 Chrome 실행 화면을 각각 1200×750, 1600×900으로 캡처했습니다.

## 내가 판단한 것

- 사용자는 규약을 먼저 읽고 새 스케치 하나를 추가하도록 지시했습니다.
- 사용자는 모델명을 GPT-6 Astra Light로 기록하도록 지정했습니다.
- 주제나 세부 모양에 대한 추가 지시 및 수정 요청은 없었습니다.

## 검증

- 로컬 헤드리스 Chrome, 1280×800에서 각도를 연속 변경하며 약 2초 동안 requestAnimationFrame 간격으로 측정한 평균은 60.0fps였습니다.
- 스케치 실행 중 콘솔 오류 및 JavaScript 예외 0개를 확인했습니다.
- 375×812 화면을 캡처해 배치와 가로 넘침이 없는 것을 확인했습니다.
- 방향키 입력, 각도 변경, 초기화 및 동작 줄이기 설정의 정지 화면을 확인했습니다.
- 목록 카드 클릭 → 뷰어 → iframe 실행 및 제작 기록 렌더링을 확인했고, 해당 경로의 콘솔 오류와 JavaScript 예외는 0개였습니다.
- devicePixelRatio 상한은 2이며 resize와 visibilitychange에 대응합니다.

## 남은 한계

- 성능 측정은 이 작업 환경의 헤드리스 Chrome 결과이며 모든 일반 노트북의 성능을 보장하지 않습니다.
- 실제 모바일 기기 및 Safari에서는 검증하지 않았습니다.
- 촘촘한 선의 간섭 무늬는 화면 해상도와 브라우저 확대율에 따라 다르게 보일 수 있습니다.

## Claude가 이어서 한 것 (2026.09)

원 기록은 위에서 끝납니다. 아래는 이 스케치를 사이트에 붙이면서 **Claude Opus 5**가 손댄 부분입니다. 무엇을 왜 고쳤는지 남깁니다.

**① 임베드용으로 페이지 크롬 제거**
스케치는 뷰어(`lab/view.html`) 안의 iframe으로 실행됩니다. 뷰어가 이미 제목·요약·RESTART 버튼을 표시하므로, 스케치가 자기 제목을 또 그리면 한 화면에 제목이 두 번 뜹니다. 그래서 왼쪽 상단의 `LAB / OPTICAL STUDY` 이름표, `Moiré Lens.` 대형 제목, 한글 부제, 그리고 RESET 버튼을 지웠습니다. ANGLE 슬라이더는 뷰어에 없는 이 스케치만의 조작이라 남겼고, 하단의 `DRAG TO SHIFT · ARROWS TO MOVE` 안내와 `INTERFERENCE / 01` 표시도 규약이 허용하는 범위라 그대로 뒀습니다. RESET 버튼을 지우면서 그 버튼을 찾는 코드가 죽지 않도록 null 검사를 한 줄 넣었습니다.

**② 구도 보정**
원래 두 원반은 화면 중앙보다 오른쪽(가로 57% 지점)에 있었습니다. 왼쪽에 제목이 놓여 있었기 때문에 맞는 배치였는데, 제가 그 제목을 지우면서 왼쪽 절반이 비어 버렸습니다. 원반 중심을 50%로, 시작 위치도 54%로 옮겨 균형을 맞췄습니다. **이건 GPT의 판단이 틀려서가 아니라 제가 제목을 없앴기 때문에 따라온 수정입니다.**

**③ 포스터 재촬영**
기존 카드·커버 이미지에는 지워진 제목과 RESET 버튼이 그대로 찍혀 있었습니다. 정리 후 화면으로 다시 찍고 색을 줄여 저장했습니다. 커버 75KB → 44KB, 카드 54KB → 28KB.

**④ 재측정**
1600×900 헤드리스 Chrome에서 **61fps**, 콘솔 오류 0개. 드래그·슬라이더 조작 후에도 동일했습니다.

> 짚어둘 점 — 이 정리가 필요했던 건 **규약(`lab/AGENTS.md`)에 "스케치는 페이지가 아니라 부품"이라는 항목이 없었기 때문**입니다. GPT는 주어진 규약을 어기지 않았습니다. 같은 일이 반복되지 않도록 그 조항을 규약에 추가했습니다.
