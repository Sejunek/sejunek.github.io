## AI가 스스로 정한 것

- 주제를 "사라진 접촉도 잠시 모양으로 남는다"로 정하고, 제목을 Memory Surface로 붙였습니다.
- 기존 Grid Field와 구분하기 위해, 점을 평면에서 밀어내는 대신 높이를 가진 막에 힘이 전파되는 표현을 선택했습니다.
- 외부 라이브러리 없이 Canvas 2D로 구현했습니다. CSS와 JavaScript를 HTML 안에 넣었으며 전역 스타일을 가져오지 않습니다.
- 67 × 45, 총 3,015개의 정점을 만들었습니다. 이웃 정점의 높이 차, 복원력과 감쇠를 1/120초 고정 간격으로 적분합니다. 과도하게 늦은 프레임은 최대 6번만 적분합니다.
- 마우스를 움직이면 표면이 약하게 반응하고, 길게 누르면 솟아오르고, 놓으면 추가 힘이 퍼지도록 했습니다. 키보드는 Space와 R을 지원합니다.
- 처음에는 두 개의 봉우리를 보여주고, 입력이 없으면 점차 평평해지도록 했습니다. RESET으로 처음의 모양을 다시 볼 수 있습니다.
- 화면 확인 후 푸른 선의 대비를 높이고, 세로로 긴 화면에서는 표면을 더 세워 보이게 투영을 바꿨습니다.
- PAUSE, 백그라운드 중단, 모션 감소 설정, 입력 취소 처리를 넣었습니다. 모션 감소 설정에서는 처음의 모양을 정지 화면으로 보여주며 포인터나 키보드로 애니메이션을 시작하지 않습니다.
- 카드와 커버는 실행한 스케치를 일시정지하고 초기 형태로 되돌린 화면을 직접 캡처했습니다. 생성 이미지나 합성 목업이 아닙니다.

## 검증

- 단일 HTML의 JavaScript 문법을 검사했습니다.
- 실행 브라우저에서 마우스 드래그를 놓은 뒤 누름 상태가 해제되는 것을 확인했습니다.
- 375 × 812에서 스케치의 가로 문서 폭이 375px임을 확인했습니다. 공용 뷰어의 모바일 iframe에서도 실행을 확인하고, 낮은 화면에서 제목과 조작 버튼이 겹치지 않도록 작은 상단 문구를 숨겼습니다.
- 실제 실행 화면을 캡처해 PNG로 저장했습니다. 카드 1200 × 750, 커버 1600 × 900의 파일 크기를 확인했습니다.
- lab/index.html에 새 카드와 AI-MADE 배지가 표시되고, 카드를 누르면 view.html?s=memory-surface로 이동하며, 실행 버튼으로 iframe이 열리는 것을 확인했습니다. 제작 기록도 뷰어 아래에 렌더됩니다.
- 스케치 단독 실행과 목록·뷰어 연결 검사에서 브라우저가 보고한 콘솔 에러는 0개였습니다.
- 별도 JavaScript 검증에서 DPR 3 입력을 2로 제한하는지, Space 해제, 일시정지 중 RESET, 백그라운드의 예약 프레임 취소와 복귀, 모션 감소의 초기 진입 및 실행 중 전환, 정지 화면의 resize 처리를 확인했습니다.
- 프레임 속도는 정상 노트북 기준으로 확정하지 못했습니다. 내장 미리보기는 지속 실행 시 약 1fps로 측정됐습니다. 캔버스와 물리 계산이 전혀 없는 별도 requestAnimationFrame 비교 화면도 지속 실행 시 1.0fps였고, 28개 측정 구간의 평균은 5.8fps였습니다. 이 환경의 결과를 일반 노트북의 렌더링 성능으로 간주하지 않았습니다.

## 남은 한계

- 일반 노트북 1280 × 800에서 최소 30fps를 만족하는지는 별도의 전경 브라우저에서 재확인이 필요합니다. 측정하지 못한 60fps를 달성했다고 적지 않았습니다.
- Canvas 2D 투영이므로 실제 3D 깊이 가림은 없습니다. 겹친 선이 함께 보이는 와이어프레임 표현입니다.
- 모바일 폭은 브라우저에서 확인했지만 실제 터치 기기 하드웨어로 시험하지는 않았습니다.
- 물리적으로 정확한 직물 시뮬레이션이 아니라 접촉과 잔상을 표현하기 위한 높이장 모델입니다.
