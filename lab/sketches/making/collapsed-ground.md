# 무너진 자리

GPT-6.1 Sol 성능 평가를 위해 요청된 스케치. 요청된 모델명을 평가 조건으로 기록하며 실제 실행 모델은 별도로 확인하지 않았다.

## 시작 프롬프트
> 새로운 인터랙션 제작을 하고자 한다. 새로 나온 GPT-6.1 Sol 의 퍼포먼스를 측정하기 위한 목적이다. 너가 기획부터 제작까지 한번 제작해보라. 단, 지금 웹 상에 업로드 되어 있는 기획과 컨셉을 카피해서는 안되며, 내가 주제를 하나 던져줄테니 한번 제작해보라.
>
> 주제 : 실패

## 기획
실패가 지워지는 게임 대신 다음 시도의 출발 조건에 남는 공간. 오래 누르면 성장하는 얇은 기둥이 자중과 작은 횡력 때문에 휘어진다. 놓으면 구조물이 무너지고, 다음 시도는 잔해 주변에서 시작한다. 목표 높이·승패·성공 메시지를 두지 않는다. 원래 상태로 돌아가는 리셋 대신 흔적을 유지한다.

독립적으로 구상했으며 타 사이트의 기획이나 소스를 참고하지 않았다. 전 세계의 유사 작품 부재를 주장하지 않는다.

## 구현과 한계
외부 의존성 없는 Canvas 2D, 고정 시간 간격 Verlet 적분, 거리 제약. 최대 약 380개의 점으로 계산 제한. 잔해의 표면은 간략한 높이 탐색이며 실제 강체 충돌 시뮬레이션은 아니다. 오래된 일부 조각은 메모리 제한을 위해 제거된다.

DPR 상한 2, 백그라운드 루프 정지, 크기 변경, 터치와 스페이스 키 지원. 움직임 감소 설정에서는 자동·입력 움직임을 정지한다.

2026-11-02: 사용자 게시 요청에 따라 LAB에 등록. 실제 실행 화면을 UI 없이 캡처하여 1200×750 카드와 1600×900 커버 생성(각 150KB 미만). 기존 공용 디자인 파일 수정 없음. FPS는 미측정이며 수치 보장하지 않음.

## 실제 검증
Chrome 1280×800에서 누르기·놓기 후 잔해 유지 확인(1회 시도, 8개 점), 페이지 오류 0개. 375px 폭에서 가로 넘침 없음. 움직임 감소 모드 전환 확인. FPS와 실제 모바일 기기 성능은 측정하지 않았다.
